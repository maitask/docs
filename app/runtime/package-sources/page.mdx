# Package Sources

Package discovery, publication, and distribution happen through Plane. Managed
Runtime workers do not keep a package catalog or source tree.

## Managed Execution

1. Publish packages through Plane.
2. Plane resolves the version and sends `code` and `version` inline on each
   execute request.
3. Runtime executes that payload. It does not call back to Plane to fetch
   package source.

## Isolated CLI Checks

To run a package without publishing it, place the files under
`~/.maitask/packages/<package-name>/` or set `MAITASK_PACKAGES_DIR`. Runtime can
browse and execute those local packages. It does not install packages from
external sources.

## Operational Guidance

- Pin package versions on published workflows.
- Treat the Plane catalog as the authority for published metadata.
- Do not copy package source onto managed Runtime worker nodes.
