# Plane Frontend

Plane Frontend is the React + Vite console for Maitask. It owns public pages,
authentication, the user console, and the platform administration console.

## Route Domains

Public routes:

- `/`, `/capabilities`, `/pricing`, `/login`, `/register`, `/terms`, `/privacy`
- `/products` redirects to `/capabilities`

User console (`/app/*`):

- `/app/dashboard`, `/app/packages`, `/app/executions`, `/app/workflows`, `/app/schedules`
- `/app/adapters`, `/app/analytics`, `/app/playground`
- `/app/settings`, `/app/notifications`, `/app/organizations`, `/app/roles`
- `/app/credits`, `/app/billing`, `/app/usage`

Administration console (`/ops/*`, platform administrators only):

- `/ops/users`, `/ops/system`, `/ops/runtime`, `/ops/runtime/releases`
- `/ops/runtime/queue`, `/ops/runtime/health`, `/ops/websocket`
- `/ops/audit`, `/ops/security`, `/ops/analytics`, `/ops/roles`, `/ops/uptime`

## Console Shell

- Desktop sidebar is transparent. The header aligns with the sidebar logo row.
- Header left: feature breadcrumb (current feature path only, no console-kind labels).
- Header right: language, theme, notifications, and user menu.
- Content sits on a rounded surface with outer `pb-2 pr-2` spacing.
- Account, billing, notification, organization, and user-settings pages use an
  in-content left-menu layout. They are not listed in the main sidebar.
- The console switch is only in the header user menu, and only for platform
  administrators.
- Brand mark is the transparent SVG glyph. Light theme uses deep black `#171719`;
  dark theme inverts it. Primary color follows that ink.
- Search fields keep the search icon inside the input. Select triggers are unframed.

## Interaction Model

- Token-based auth is persisted in browser storage, with a synced cookie for WebSocket auth.
- The Plane API client handles timeout, cache deduplication, and normalized errors.
- Browser workflows talk to Plane APIs, not directly to Runtime.
- Execution updates arrive through Plane WebSocket endpoints.
- Tenant actions are gated with `PrivateRoute` and `TenantPermissionRoute`.
  Administration routes additionally require a platform administrator.

## Billing And Credits

- Billing and Credits load payment capabilities from `GET /payments/config`.
- Provider lists are runtime-driven (`stripe`, `paypal`, optional `alipay`, `wechat_pay`).
- When payments are disabled or no provider is configured, user self top-up is unavailable.
- Credits top-up uses provider checkout redirects; direct credit grants are administrator-only.
