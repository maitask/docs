# FAQ

## Why did my execution fail with authentication errors?

Validate user token (frontend/API) and service HMAC configuration (Runtime to Plane) separately. They are different trust paths.

## Why does a package execute in local but fail in production?

Check runtime execution policy differences: network allow-list, timeout, memory limits, and signature requirements.

## Why are schedules not firing?

Verify schedule enablement, next run timestamp, scheduler service health, and trigger data validity.

## Why are credits not deducted as expected?

Check reserve, consume, and refund transactions for the execution ID in Plane credits history.
Successful model steps also consume prompt and completion tokens at the platform
policy rates. Agent child executions settle independently; the parent agent node
does not bill those tokens again.

## How do I generate a workflow with a model?

Use **Generate draft** in the workflow list or editor. Plane calls
`POST /workflows/drafts` with the official package catalog. Review the proposed
graph, then confirm to create or apply it. The request does not create a live
workflow by itself.

## Why did an agent node fail without producing copy?

Agent nodes fail closed when the API key is missing, the planner returns invalid
JSON, a selected package is outside the allowlist, or `max_steps` is reached
before `finish`. Tool failures are returned to the planner as observations;
planner and credential failures stop the node.

## Where should package metadata be managed?

Manage published package metadata in Plane. Runtime should be treated as execution engine and cache layer.
