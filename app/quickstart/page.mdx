# Quick Start

## Prerequisites

- Rust 1.70+
- Node.js 20+
- PostgreSQL 14+
- Redis 7+

## 1. Start Runtime

```bash
cd runtime
MAITASK_PACKAGES_DIR=../packages \
cargo run --locked -- serve --http-host 127.0.0.1 --http-port 8080
```

## 2. Start Plane

```bash
cd plane
cp .env.example .env
sqlx migrate run
cargo run
```

## 3. Start Plane Frontend

```bash
cd plane-frontend
npm install
npm run dev
```

Frontend default URL: `http://localhost:3000`
Plane default URL: `http://localhost:8001`
Runtime default URL: `http://localhost:8080`

## 4. Verify Health

```bash
curl http://localhost:8001/health
curl http://localhost:8080/health
```

## 5. First Execution

```bash
cd runtime
printf '%s' '{"text":"name,age\\nAlice,30"}' \
  | MAITASK_PACKAGES_DIR=../packages \
    cargo run --locked -- run @maitask/csv-parser
```
