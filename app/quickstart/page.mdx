# Quick Start

## Local Console Against Development Data

Start local Plane and the console against development PostgreSQL, Redis, MinIO,
and tenant data. The script retrieves secrets transiently; do not copy those
values into files, logs, or commits.

```bash
scripts/start-local-with-development-data.sh
```

Default local URLs:

- Frontend: `http://127.0.0.1:3000`
- Plane: `http://127.0.0.1:8001`

The development Plane must remain healthy so it retains the distributed
scheduler lock.

## Isolated Runtime Package Run

Runtime workers in managed environments are native binaries. For a local
package smoke check:

```bash
cd runtime
printf '%s' '{"text":"name,age\\nAlice,30"}' \
  | MAITASK_PACKAGES_DIR=../packages \
    cargo run --locked -- run @maitask/csv-parser
```

## Verify Health

```bash
curl -fsS http://127.0.0.1:8001/health
```
